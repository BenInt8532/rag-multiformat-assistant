# Материалы к статье «Оценка RAG: где ошибается RAGAS и как его проверить»

Здесь лежит всё, чтобы повторить числа статьи: проверка ответов по ключам, сравнение судьи RAGAS с ключами, опыты с судьёй и логи прогонов, на которых они посчитаны. Код самого ассистента — в корне репозитория, эта папка его не меняет.

## Что где

| Файл или папка | Что это |
|---|---|
| `klyuchi.py` | ключи к вопросам: «ключ куска» (фразы, без которых ответить нельзя) и «ключ ответа» (что обязано быть в верном ответе) |
| `razbor.py` | проверка прогона по ключам: верен ли ответ, дошёл ли нужный кусок до модели, был ли отказ; без обращений к API |
| `sudya_vs_klyuchi.py` | сводка «судья RAGAS против ключей»: оценки судьи у верных и неверных по ключам ответов |
| `sostav_progonov.py` | из 48 прогонов какие на рабочих настройках, какие с нарочно испорченной нарезкой, какие — опыты с настройками |
| `sudya_opyt.py` | опыт: тот же ответ как есть, с подписью источника и с фразой отказа вместо ответа (25 ответов, по 3 оценки) |
| `opyt_shum.py` | опыт: один и тот же ответ, 20 оценок судьи — чистый шум судьи |
| `opyt_otkazy.py` | опыт: те же куски, меняется только фраза отказа (заданная или своя), по 10 оценок |
| `opyt_podpis.py` | опыт: ответ без подписи, с правильной и с искажённой подписью источника, по 10 оценок |
| `sudya_obshchee.py` | общая часть трёх опытов выше |
| `progony/` | логи 68 прогонов ассистента (12–15 октября 2026): вопросы, найденные куски, ответы, оценки судьи |
| `opyty/` | результаты опытов, по которым написана статья |

## Как повторить

Все команды — из корня репозитория, после установки по основному README.

Без API (только чтение логов):

```
python statya-ocenka/razbor.py statya-ocenka/progony/2026-10-12-130153-uniform-real-topk8-ragas.json statya-ocenka/progony/2026-10-12-130825-rules-real-topk8-ragas.json
```
Главный замер: 20 и 25 верных из 29, нужный кусок дошёл до модели в 21 и 24 вопросах из 26.

```
python statya-ocenka/sostav_progonov.py
```
Состав 48 прогонов, на которых судья сравнивался с ключами: 17 рабочих, 7 с испорченной нарезкой, 24 опыта.

`sudya_vs_klyuchi.py` принимает список прогонов. Для чисел статьи нужны 48 прогонов с оценками судьи с 12.10 04:50 по 14.10 21:31 (их и выбирает `sostav_progonov.py`). Итог: 696 ответов, 528 верных и 69 неверных по ключам, неверных с Faithfulness 0.9 и выше — 20.

С API (нужен ключ OpenAI в `.env`, как для самого ассистента; судья — `gpt-4o-mini`):

```
python statya-ocenka/opyt_shum.py statya-ocenka/progony/2026-10-14-215644-rules-real-topk8-ragas.json
python statya-ocenka/opyt_otkazy.py statya-ocenka/progony/2026-10-12-020759-uniform-topk3-ragas.json
python statya-ocenka/opyt_podpis.py statya-ocenka/progony/2026-10-14-215644-rules-real-topk8-ragas.json
python statya-ocenka/sudya_opyt.py statya-ocenka/progony/2026-10-14-215644-rules-real-topk8-ragas.json
```
Результат каждого пишется в `statya-ocenka/opyty/`. Оценки судьи плавают от запуска к запуску, поэтому числа повторятся близко, но не обязательно до сотых.

## Ограничения

- Ключи — приближение: скрипт ищет фразы как кусок текста, а не понимает смысл. Короткий ключ может совпасть внутри другого слова или числа («5» внутри «15»). На 528 засчитанных ответах 48 прогонов проверено отдельно, с границами слов и чисел: ни один зачёт на таком совпадении не держится.
- Отказом считается только ответ, который точно совпадает с заданной фразой «В документах нет информации по этому вопросу.». Отказ своими словами скрипт считает обычным ответом. В 48 прогонах промпт требовал заданную фразу, и модель отказывала ею.
- `razbor.py` пропускает вопросы без ключа и логи без поля отказа (шесть ранних прогонов 12.10) и пишет, сколько пропущено.
- Повторный запуск опыта не затирает результаты статьи в `opyty/`: новый результат пишется рядом, со временем в имени файла.
- Каждый ответ, который скрипт счёл неверным, перечитывал агент Claude Code; засчитанные ответы главного замера отдельно перечитала другая модель (gpt-4.1).
- Логи сняты на одной вымышленной базе из 9 файлов (папка `data/` в корне) и с одной моделью для ответов и для судьи.
- В логах есть прогоны на наборах `questions-pdf.json` и `questions-tablicy.json`: это опыты статьи про нарезку, сами наборы в эту папку не входят, их вопросы и ответы видны в логах.
